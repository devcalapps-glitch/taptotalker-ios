# TapToTalker

Offline AAC communication for people who build spoken messages by tapping picture cards. Caregivers configure the board; the communicator uses it.

## Language

### People

**Communicator**:
The person who taps cards to speak.
_Avoid_: User, child, patient, client

**Caregiver**:
The person who sets up vocabulary level, customizes cards, and locks settings.
_Avoid_: Parent, admin, teacher (unless that role is itself a card label)

### Board & message

**Board**:
The current screen of tappable choices.
_Avoid_: Grid, page, menu, home screen (except when naming the root board)

**Card**:
One tappable choice with a label and symbol that can lead to more choices or finish a phrase.
_Avoid_: Tile, button, option, icon

**Starter**:
A top-level card on the home board that begins a message path (for example “I want to”, “I feel”).
_Avoid_: Category, folder, root option

**Path**:
The ordered sequence of cards chosen so far in one message.
_Avoid_: Stack, history, trail

**Phrase**:
The spoken sentence formed from the labels on the current path.
_Avoid_: Sentence, utterance, message text

**Prompt**:
The question shown for the current board that guides the next tap.
_Avoid_: Title, headline, instruction

### Vocabulary depth

**Vocabulary mode**:
How wide and deep the board is — Simple, Intermediate, Guided, or Advanced.
_Avoid_: Level (except in caregiver-facing copy), difficulty, tier, preset

**Step**:
One card choice along the path toward a finished phrase.
_Avoid_: Level, page, hop

**Detail card**:
A deeper choice that only appears in richer vocabulary modes (Advanced).
_Avoid_: Sub-option, leaf variant

### Customization

**Card mode**:
Whether the board shows built-in cards, caregiver customizations, or edit controls (Default, Custom, Edit).
_Avoid_: Theme, skin, display mode

**Override**:
A caregiver change to a card’s label, emoji, or photo that replaces the built-in version when Custom or Edit is active.
_Avoid_: Patch, customization record, mutation

**Onboarding**:
First-run caregiver setup: vocabulary mode, optional card personalization, and optional PIN.
_Avoid_: Wizard, tutorial, intro

### Safety

**Caregiver PIN**:
Optional numeric lock that gates caregiver settings.
_Avoid_: Password, passcode, auth
